# To-Do List Application

A small Python project developed for practice, featuring a user interface that allows users to manage daily tasks and track completed activities.

## Features

- **Add Tasks (`addTask()`):** Adds new tasks to the to-do list while checking for empty inputs and duplicate entries.
- **View Tasks (`toDo()`):** Displays all currently pending tasks.
- **Mark Tasks as Complete (`markComplete()`):** Removes a task from the pending list and transfers it to the completed tasks list. Includes validation to prevent empty inputs and duplicate entries.
- **View Completed Tasks (`completed()`):** Displays all completed tasks.

## Project Goals

This project was created to practice Python programming, strengthen understanding of functions and list management, and gain experience developing a user interface for a simple task management application.
